# DSH Desktop 使用手册

## 1. 双轨架构

| 角色 | 端口 | 运行方式 | 数据目录 | 用途 |
|---|---|---|---|---|
| 开发端 | 3080 | 用户级 systemd / 客户端托管 | `~/.dsh`（user） | 日常开发，浏览器或桌面端均可连接 |
| root 测试端 | 3081 | 系统级 `dsh-web-root.service`（root） | `~/.dsh-root`（隔离） | 需要系统权限的测试/开发 |

- 两套服务互相独立，可同时运行；桌面客户端可在诊断面板一键切换。
- root 端存储独立，避免把 `~/.dsh` 写成 root 所有；如误写，可执行
  `sudo /usr/local/sbin/dsh-fix-owner` 修复。

## 2. 桌面客户端

- 启动：应用菜单「DeepSeek Harness」或 `~/.local/bin/dsh-desktop`
- 服务模式：`externalService=true` 时客户端只连接配置端口，不自己拉起服务
- 切换服务：设置/诊断面板 →「连接开发服务(3080)」/「连接 root 测试(3081)」
- 关闭行为：托盘（默认）/ 退出客户端（保留服务）/ 退出并停止服务

## 3. 附件（图片/文件）

- dsh 原生支持：把图片/文件拖入窗口，或直接粘贴，即可作为附件（最多 20 张，
  每张 20MB）；提示层会在松手后自动收起。
- 客户端不再拦截拖拽/粘贴，避免提示层状态残留。
- 长文本粘贴（默认 > 6000 字符）：自动保存为
  `~/.config/dsh-desktop/pastes/paste-<时间>-<首行摘要>.txt`，并在输入框插入路径。
  可在设置中开关/调整阈值。

## 4. 文件夹工作区

- 菜单「打开文件夹作为工作区…」→ 为该文件夹启动独立 dsh web 实例并开新窗口；
- 菜单「最近工作区」可一键重开最近 8 个文件夹；
- 每个工作区实例约占 1GB 内存，关闭窗口即自动停止释放。

## 5. 多窗口与最近会话

- `Ctrl+Shift+N` 新建窗口（同一服务、不同会话视图）；
- 应用/托盘菜单「最近会话」可打开最近会话。

## 6. 更新与回滚

- dsh 运行时：菜单检查更新，确认框可「查看更新说明」；设置里可配置镜像源与检查频率；
- 客户端壳：菜单「检查客户端更新」；诊断面板「回滚客户端版本」/「回滚 dsh 运行时」；
- 诊断面板：导出诊断包、备份会话、导出最近会话 Markdown、清理缓存、修复属主。

## 7. 故障排查

- 界面模糊：历史问题已修复（dsh 原生拖拽提示层残留）；若出现请按 Esc；
- 服务连不上：客户端会等待并自动重连（外部服务模式最多 90–120 秒），
  也可诊断面板「重启后台服务」或检查 `systemctl --user status dsh-web-session.service`；
- 日志：`~/.config/dsh-desktop/main.log`、`server.log`、`systemd-server.log`；
  拖拽问题会记录 `[drop-diag]` 并保存 `drop-diag-latest.png`；
- root 端：`systemctl status dsh-web-root.service`。

## 8. 迁移与回滚

详见 [migration.md](migration.md)：确认稳定后把客户端指向开发端或切到 systemd 用户服务；
出问题可随时用浏览器打开 3080 的 token URL 继续工作。
